# YOA Translation

Профессиональный литературный перевод серии **«The Years of Apocalypse»** UraniumPhoenix на русский язык.

Серия из 4 книг, прогрессивная фэнтези с временной петлёй. Перевод ведётся в порядке: Книга 1 → 2 → 3 → 4. Текущая работа — Книга 1, главы 1–81.

Перевод неофициальный, для узкого круга. Делается с применением AI-инструментов (Claude) под руководством редактора. Подход — литературный, не машинный: каждая глава проходит несколько проходов, ведётся живой глоссарий, фиксируются стилистические решения.

## Текущий статус

См. [`next.md`](./next.md) — там всегда самая свежая сводка: где мы находимся, что сделано, что нерешённого, и куда двигаться дальше.

Для краткого старта в новой сессии Claude: дай ссылку на репо и фразу вроде «продолжаем работу, глава N» — Claude прочитает `next.md`, глоссарий и нужные файлы skill сам.

## Условные обозначения

- ⚠ в глоссарии — нерешённый или спорный вопрос, требующий обсуждения
- В чек-листе и стиле — **жирным** выделены критические правила, которые нельзя нарушать без обоснования

## Подключение skill в Claude

1. Скачать `yoa-translation.skill` (собирается из содержимого `skill/`)
2. В Claude: **Settings → Capabilities → Skills → Upload skill**
3. После установки skill автоматически активируется в чатах, где упоминается перевод этой книги
