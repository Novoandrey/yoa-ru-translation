# Формат глоссария

Глоссарий живёт в файле `glossary.md` в корне проекта книги. Он — рабочий документ, не окаменевший: его дополняет пользователь по ходу работы, ты предлагаешь записи.

## Структура файла

Глоссарий делится на разделы. Порядок внутри разделов — алфавитный по русскому варианту.

```
# Глоссарий — Книга 1

## Персонажи
## Места (топонимы)
## Государства и народы
## Магия и арканная теория
## Заклинания
## Существа (мирвиты и прочие)
## Предметы и артефакты
## Учреждения, факции, организации
## Титулы, звания, должности
## Единицы измерения и календарь
## Боги, религии, мифология
## Прочее
```

## Запись персонажа (одушевлённое имя)

```markdown
### Mirian Castrella — Мириан Кастрелла
- **Род:** ж.
- **Падежи (ед.):** Мириан Кастрелла / Мириан Кастреллы / Мириан Кастрелле / Мириан Кастреллу / Мириан Кастреллой / о Мириан Кастрелле
- **Имя (Мириан):** несклоняемое (иностранное на согласную в женском имени — закрепляем как несклоняемое, иначе выйдет громоздко)
- **Фамилия (Кастрелла):** склоняется по 1-му скл.
- **Уменьшительные:** Мири (в устах близких — Лили, Николуса, семьи)
- **Первое появление:** гл. 1
- **Альтернативы отвергнуты:** «Мириана» (русификация через -а — лишнее, звучит как румынское), «Мирьян» (не передаёт английское звучание)
- **Примечания:** главная героиня. В официальных обращениях — «Мириан Кастрелла», в неформальных — просто «Мириан».
```

Для двусоставных имён склоняется каждая часть отдельно — следи за окончаниями.

## Запись имени-фамилии с феминитивом/гендером для ролей

Если персонаж — носитель роли, которая имеет феминитивную форму (архимаг/архимагесса и т.д.), роль указывается отдельно в разделе «Титулы», а тут — ссылка.

## Запись топонима

```markdown
### Torrviol — Торрвиоль
- **Род:** м. (оканчивается на мягкий знак, ассоциируется с «городом»)
- **Падежи:** Торрвиоль / Торрвиоля / Торрвиолю / Торрвиоль / Торрвиолем / в Торрвиоле
- **Прилагательное:** торрвиольский (Торрвиольская Академия, торрвиольский стражник)
- **Житель:** торрвиолец / торрвиолка / торрвиольцы
- **Первое появление:** гл. 1
- **Обоснование:** удвоенное «рр» сохраняем из оригинала, «io» даёт «иоль» по традиции (ср. Брюссель→Брюссе-ль). Буква «ь» на конце делает мужской род очевидным.
- **Альтернативы отвергнуты:** Торрвиол (без мягкого знака — звучит обрубленно), Торвиоль (одна «р» — теряет звукопись оригинала)
```

## Запись термина магической системы

```markdown
### myrvite — мирвит
- **Род:** м. (неодуш.)
- **Падежи (ед.):** мирвит / мирвита / мирвиту / мирвита / мирвитом / о мирвите
- **Мн. ч.:** мирвиты / мирвитов / мирвитам / мирвитов / мирвитами / о мирвитах
- **Прилагательное:** мирвитный (мирвитная ткань, мирвитное мясо)
- **Определение:** магическое существо/растение мира Энтерии; могут быть хищниками, травоядными, флорой
- **Первое появление:** гл. 1 (здание Исследований Мирвитов)
- **Обоснование:** транслит сохраняем — это авторский неологизм, ключевой термин мира. «-ит» даёт ему звучание класса существ, как «аммонит», «трилобит». Одушевлённость — сложный вопрос: формально мирвит может быть и животным, и растением. Принимаем как НЕОДУШЕВЛЁННОЕ в склонении (родительный = винительный в ед.ч.: «увидела мирвита» — НЕТ, правильно «увидела мирвит» как «увидела камень»). Исключение: когда речь идёт о конкретном хищнике-мирвите как о животном, допустимо «увидела мирвита» (разговорное). Финализируем по ходу.
- **Альтернативы отвергнуты:** мирвайт (ближе к англ., но выглядит чужеродно), мирвид (меняет смысл)
```

## Запись заклинания

```markdown
### force drill — силовой бур
- **Род:** м.
- **Падежи:** силовой бур / силового бура / ... 
- **Категория:** force spell / силовое заклинание
- **Первое появление:** гл. 43
- **Обоснование:** «бур» лучше чем «дрель» — архаичнее, ближе к фэнтези-регистру. «Drill» тут — не буквальный инструмент, а действие проникновения.
- **Варианты в тексте:** «применила силовой бур», «заряд силового бура»
```

## Запись титула с феминитивом

```markdown
### Archmage — архимаг / архимагесса
- **Мужской род:** архимаг, -а, -у, -а, -ом, -е (мн. архимаги)
- **Женский род:** архимагесса, -ы, -е, -у, -ой, -е (мн. архимагессы)
- **Первое появление:** гл. 69 (архимаг Луспайр)
- **Обоснование:** феминитив «архимагесса» закрепляется — в переводе уже появлялось «Архимагесса Мириан Кастрелла» в главе 167. Соответствует «поэтесса, принцесса» по модели. Вариант «архимагиня» отвергнут — звучит неестественно, «магиня» в русском почти не прижилось.
- **Отвергнутые альтернативы:** «архимагиня» (неестественно), «женщина-архимаг» (казённо), оставить без феминитива (противоречит принципу)
```

## Правила ведения

**Одно решение — навсегда.** Если термин закреплён в глоссарии, во всех главах должна быть эта форма. Если встретил противоречие в уже переведённых главах — отметь и правь при ретро-редактуре.

**Падежи — не опционально.** Особенно для имён/фамилий на редкие окончания, для топонимов с нестандартным родом, для транслитов. Без полной парадигмы переводчик через 50 глав сам забудет, как склонял, и начнёт плодить варианты.

**Обоснование — не формальность.** Запиши КАКУЮ проблему решает этот вариант и какие альтернативы отвергнуты. Через три месяца ни ты, ни автор не вспомните, почему «Кастрелла», а не «Кастрель».

**Первое появление — для ретро-сверки.** Чтобы при изменении решения понять, сколько глав надо править.

**Феминитивы фиксируем при первом женском носителе роли**, не дожидаясь. Если в главе 5 появилась женщина-капитан — заводим «капитан / капитанша» (или «женщина-капитан», или какое решение примем) СРАЗУ, не «когда-нибудь».
