# Фазы пайплайна

Текущее положение для Книги 1:

## Фаза 0. Preflight — ЗАВЕРШЕНА
- Жанр и целевая аудитория определены (progression fantasy / time loop, adult YA).
- Книжная структура зафиксирована: Книга 1 = главы 1–81.
- Авторские глоссарии найдены (Version 1 на RR, Version 2 для Книги 3).

## Фаза 1. Style Bible — В РАБОТЕ
- Авторский голос описан в `style-guide.md`.
- Правила русификации, включая латинское правило, зафиксированы.
- Ругательства и феминитивы — отдельными документами.
- **Осталось:** обкатать на 1–2 главах, подшлифовать по результатам.

## Фаза 2. Glossary v1 — В РАБОТЕ
- Стартовый глоссарий создан из авторских источников и уже-переведённого.
- **Осталось:**
  - Извлечь все термины из английских глав 30–81.
  - Сверить с уже-переведёнными главами 1–29 (искать расхождения и кальки).
  - Для каждого склоняемого имени — полная парадигма падежей.
  - Обсудить спорные решения с пользователем, финализировать v1.

## Фаза 3. Ретро-редактура глав 1–29
- Применить финализированный глоссарий — массовые замены (Николус → Никол и т.п.).
- Точечная правка калькированных мест.
- Сверка типографики и пунктуации.
- НЕ переписывать с нуля — сохраняем живые обороты переводчика.

## Фаза 4. Перевод глав 30–81
- По главе за сессию (или несколько).
- Внутри главы: прочёл оригинал целиком → проверил термины → перевёл → перечитал → чек-лист → сдал.
- Глоссарий обновляется по ходу.

## Фаза 5. Passes (проходы по всей книге)
- **Consistency pass** — поиск всех терминов по падежам через регулярные выражения, проверка единства.
- **Line-edit pass** — охота на «переводизмы», кальки, русские обороты.
- **Proofreading pass** — типографика, пунктуация, неразрывные пробелы.
- **Read-aloud pass** — чтение вслух или через TTS. Всё что спотыкается — переписать.

## Фаза 6. Beta reading
- 2–3 читателя разной степени требовательности. Сбор правок.

## Фаза 7. Final polish + публикация

---

Ориентируйся в разговоре: если пользователь принёс главу на перевод — мы в Фазе 4. Если редактирует уже переведённое — Фаза 3. Если обсуждаем решения по терминам — Фаза 2. Если обсуждаем тон — Фаза 1.
