# Чек-лист контроля качества — проходить после перевода главы

## 1. Терминология

- [ ] Все имена собственные сверены с `glossary.md`. Падежи — по парадигме из глоссария.
- [ ] **Особо проверить склонение ключевых терминов: мана/маны/мане/ману/маной (НЕ «поток мана»), мирвит, Торрвиоль, Баракэль и пр. Это типичная зона ошибок при беглом наборе.**
- [ ] **Проверить каждое местоимение в близости к двум кандидатам одного грамматического рода — особенно после диалогов и в сценах с двумя персонажами одного пола (Мириан + Лили / Вален / Нуреа). Если есть колебание — заменить на имя.**
- [ ] **Проверить сложноподчинённые предложения: не пропущен ли союз «что» / «который» / «когда»? Особенно в конструкциях типа «казалось, [что] всё это…», «знала, [что] нужно…».**
- [ ] Новые термины добавлены в глоссарий (с падежами, родом, обоснованием), если встретились в этой главе.
- [ ] Латинские/псевдолатинские имена обработаны по правилу: -us/-ius/-um отброшены или трансформированы (Nicolus → Никол, Aurelius → Аврелий). См. `style-guide.md`.
- [ ] Феминитивы применены по `feminitives.md`.
- [ ] Если термин переведён иначе, чем в главах 1-29 — отмечено для ретро-редактуры.

## 2. Живость и читаемость

- [ ] Нет явных калькированных притяжательных: «поднял свою руку», «взял её руку в свою».
- [ ] Нет избыточного «был + причастие» там, где русский хочет активного залога.
- [ ] Цепочки «который... который...» и «что... что...» разбиты.
- [ ] Длинные англ. предложения разбиты или перестроены, где это улучшает ритм.
- [ ] Короткие рубленые предложения в экшене НЕ склеены в длинные.
- [ ] Нет ненужных «это», «тот», «этот» (кальки с артиклей).
- [ ] Диалоги звучат устно, а не письменно.

## 3. Авторский голос

- [ ] «Щёлчки» иронии в конце абзацев сохранены.
- [ ] Академический регистр в рефлексии Мириан — сохранён, не упрощён.
- [ ] Внутренние мысли (курсив) переведены и выделены.
- [ ] Стилистические различия в речи разных персонажей — читаются.
- [ ] **Атрибуция диалога экономна:** «сказал/сказала» в нарративе — не больше 8–10 на главу. Где можно срезать или заменить точным глаголом действия — сделано.

## 4. Ругательства

- [ ] Ругательства по шкале из `swearing.md`. Нет «стерилизации» сильных выпадов. Нет избыточного мата там, где его нет.
- [ ] Five hells / Gods / damn — по закреплённым решениям.

## 5. Русская типографика

- [ ] Прямая речь — через длинное тире (—), не дефис (-).
- [ ] Кавычки — «ёлочки», не "" и не '' ни в одном месте.
- [ ] Многоточия — одним символом (…), не три точки.
- [ ] Тире между подлежащим и сказуемым-существительным стоит, где нужно.
- [ ] Нет двойных пробелов, нет пробелов перед знаками препинания.
- [ ] Неразрывные пробелы там, где важны (г. Торрвиоль, 3 сентября и т.п.) — опционально, но желательно.
- [ ] **Тире вне прямой речи — только по функции (пропуск, противопоставление, подлежащее=сказуемое, длинная парентеза). Связки «Х — но Y» / «Х — и Y» — срезать на запятые. См. правило в `style-guide.md`.**
- [ ] **Знак тире — длинное (—) во ВСЕХ пунктуационных функциях, включая прямую речь. Среднее (–) только в числовых диапазонах (5–10). Без смешения. См. `style-guide.md`.**

## 6. Согласованность внутри главы

- [ ] Один персонаж — одна форма имени в нарративе. (В диалогах может быть «Мириан» и «Мири» — это характеристика говорящего.)
- [ ] Заклинания, места, звания — одинаково транслитерированы на протяжении главы.
- [ ] Времена и виды согласованы; нет скачков «шла — идёт — пошла».

## 7. Фактологическая проверка

- [ ] Смысловые ошибки — нет (проверить сомнительные места, сверившись с оригиналом).
- [ ] Игра слов и аллюзии — сохранены или адаптированы, не потеряны.
- [ ] Имена и числа — не перепутаны с оригиналом.

## 8. Финальное чтение

- [ ] Глава прочитана подряд после перевода — «свежим глазом».
- [ ] Нет мест, где взгляд спотыкается.
- [ ] Ритм держится на протяжении главы.

## Отчёт пользователю

В конце сдачи главы дай короткий отчёт (2–5 пунктов):
- Новые термины в глоссарии (с предложенными переводами)
- Стилистические решения, которые стоит зафиксировать
- Спорные места, где нужна обратная связь
- Места, которые потребуют ретро-правки в главах 1-29 (если нашлись несоответствия)
