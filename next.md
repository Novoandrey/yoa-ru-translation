## Массовые ретро-замены для глав 5–29

Главы 5–29 существуют в раннем переводе `novoandrey`. При ретро-редактуре нужно применить:

1. **Николус → Никол** (~116 вхождений) — латинское правило
2. **Дресс-код → устав формы** — англицизм
3. **Жилищный отдел → комендантская**
4. **Ударное заклинание → силовое заклинание**
5. **Киpосцентский → Киросцентский** (опечатка с латинской `p`)
6. **штаны → брюки** (для консистентности с уставом формы)
7. **Среднее тире (–) → длинное (—)** в пунктуации (если есть смешения)
8. **«сказала» — экономия** (≤8–10 на главу)
9. **Рифт-море / Море Рифта → Разломное Море** — если встречалось в раннем переводе
10. **рипост → ответный удар / контратака** — если встречалось

## Применённые принципиальные решения

См. `decisions/` для подробного обоснования. Ключевые:

- **Длинное тире (—)** во всех функциях, среднее (–) только в диапазонах. **≤5 тире вне прямой речи на главу.**
- **Латинские -us/-um** отбрасываем (Nicolus → Никол, Aurelius → Аврелий, Platus → Плат).
- **Заглавные** в учебных дисциплинах (Алхимия, Зачарования, Артефакторика, Арканная Математика, Физическая Подготовка, Продвинутое Усиление Заклинаний, Алхимическая Промышленность).
- **Курсы с номером** через дефис без пробела (Алхимия-402).
- **Метрические единицы** для имперских (3 inch → 8 cm), миля и драхма как есть.
- **Spellforge factory → фабрика-кузня** (с аллюзией на советскую фабрику-кухню).
- **Family** в контексте привилегий → «дворянская семья».
- **Ругательства** по шкале с переводческой традицией смягчения; «Five hells» → «пять преисподних».
- **Феминитивы** систематически: архимагесса, пророчица, заклинательница, первопроходица.
- **Названия глав** — близко к авторскому варианту, без редакторских «смысловых» переименований.
- **Курсив для всех внутренних мыслей** — сохраняем (даже если у автора в этом месте курсива нет). Артефакт копипаста из Google Docs — не решение.
- **Rift Sea → Разломное Море** (калька, как Курганпасть).
- **Акана** склоняется (1 скл. ж.р.), Праэдиар нет.
- **Фехтовальная терминология** — без жаргонного транслита: riposte → ответный удар, lunge → выпад, и т.д.
- **magitech → магтех** (не магитех), **mana refinery → очистительный мана-завод**.

## Примечание про push

В этой настройке проекта токен GH_TOKEN не пробрасывается автоматически в bash-окружение (env пустой при старте сессии). Для push нужен явный setup:
1. Создать `~/.git-credentials` с токеном из системного промпта
2. `chmod 600 ~/.git-credentials`
3. `git config --global credential.helper store`

Это нужно делать в начале каждой сессии (sandbox /home/claude сбрасывается). В других проектах пользователя env прокидывается автоматически — здесь, видимо, другая конфигурация.
