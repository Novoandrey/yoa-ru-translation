## Массовые ретро-замены для глав 5–29

Главы 5–29 существуют в раннем переводе `novoandrey`. При ретро-редактуре нужно применить:

1. **Николус → Никол** (~116 вхождений) — латинское правило
2. **Дресс-код → устав формы** — англицизм
3. **Жилищный отдел → комендантская**
4. **Ударное заклинание → силовое заклинание**
5. **Киpосцентский → Киросцентский** (опечатка с латинской `p`)
6. **штаны → брюки** (для консистентности с уставом формы)
7. **Среднее тире (–) → длинное (—)** в пунктуации (если есть смешения)
8. **«сказала» — экономия** (≤8–10 на главу)

## Применённые принципиальные решения

См. `decisions/` для подробного обоснования. Ключевые:

- **Длинное тире (—)** во всех функциях, среднее (–) только в диапазонах.
- **Латинские -us/-um** отбрасываем (Nicolus → Никол, Aurelius → Аврелий).
- **Заглавные** в учебных дисциплинах (Алхимия, Зачарования, Артефакторика, Арканная Математика, Физическая Подготовка).
- **Курсы с номером** через дефис без пробела (Алхимия-402).
- **Метрические единицы** для имперских (3 inch → 8 cm), миля и драхма как есть.
- **Spellforge factory → фабрика-кузня** (с аллюзией на советскую фабрику-кухню).
- **Family** в контексте привилегий → «дворянская семья».
- **Ругательства** по шкале с переводческой традицией смягчения; «Five hells» → «пять преисподних».
- **Феминитивы** систематически: архимагесса, пророчица, заклинательница, первопроходица.
- **Названия глав** — близко к авторскому варианту, без редакторских
  «смысловых» переименований; число и нумерация сохраняются
  (Nightmares → Кошмары, Academic Life 2 → Академическая жизнь 2).
